licencia siguen siendo tuyas. No puedes seguir haciendo modificaciones
privadas a partir de nuevas versiones.

**¿Puedo contratar desarrollo a medida?**
Sí. Presupuesto aparte según el alcance. La licencia comercial cubre el
derecho de uso del código base, no el desarrollo de funcionalidades nuevas.
